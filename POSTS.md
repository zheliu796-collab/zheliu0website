# Adding a post

Create content/en/posts/your-post-title/index.md with title, date, description, and draft: true in YAML front matter. Write Markdown below it. Keep images in the same folder.

Set draft: false when ready, and commit to master to publish. Posts appear at /posts/, newest first. Existing engineering projects in content/en/post/ stay separate.

With Hugo installed, run: hugo new posts/your-post-title/index.md
